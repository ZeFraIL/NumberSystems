# Detailed Class Description: CalculatorFragment

#### 1. General Information
- **Class Name:** `CalculatorFragment`
- **Type:** Fragment (UI Controller)
- **Role:** Handles expression calculator UI. Captures math expression, handles quick operator buttons (`+`, `-`, `*`), calls `ExpressionEvaluator.evaluate()`, and opens `CustomResultsDialog`.
- **UI Components:** `RadioGroup` (`rgCalcSystems`), `TextInputEditText` (`etCalcExpression`), operator buttons, `MaterialButton` (`btnCalculate`).

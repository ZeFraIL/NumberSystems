# Detailed Class Description: CustomResultsDialog

#### 1. General Information
- **Class Name:** `CustomResultsDialog`
- **Type:** Dialog Utility Class
- **Role:** Creates and manages a Material 3 `BottomSheetDialog` displaying conversion/calculation results for all 6 systems.
- **Methods:** `show(context, title, subtitle, items)` inflates `dialog_results.xml`, sets subtitle, attaches `ResultsAdapter`, and displays the modal bottom sheet.

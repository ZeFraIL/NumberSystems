# Detailed Class Description: ConverterFragment

#### 1. General Information
- **Class Name:** `ConverterFragment`
- **Type:** Fragment (UI Controller)
- **Role:** Handles number conversion UI ("All Types"). Captures number input, validates input, calls `NumberConverter.convertAll()`, and opens `CustomResultsDialog`.
- **UI Components:** `RadioGroup` (`rgSystems`), `TextInputLayout` (`tilInput`), `MaterialButton` (`btnConvert`).

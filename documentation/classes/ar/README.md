# توثيق مفصل لجميع فئات المشروع (العربية)

التوثيق الكامل لجميع فئات Java الـ 15 في التطبيق:

1. [SplashActivity.md](SplashActivity.md) - شاشة البدء (عرض الشعار لمدة 4 ثوانٍ)
2. [MainActivity.md](MainActivity.md) - النشاط الرئيسي المستضيف لـ ViewPager2 و TabLayout
3. [ConverterFragment.md](ConverterFragment.md) - واجهة تحويل الأرقام ("All Types")
4. [CalculatorFragment.md](CalculatorFragment.md) - واجهة حاسبة التعابير
5. [ViewPagerAdapter.md](ViewPagerAdapter.md) - محول التبويبات لـ ViewPager2
6. [CustomResultsDialog.md](CustomResultsDialog.md) - نافذة النتائج المخصصة (Material 3 BottomSheetDialog)
7. [ResultsAdapter.md](ResultsAdapter.md) - محول قائمة النتائج مع زر النسخ
8. [ResultItem.md](ResultItem.md) - نموذج بيانات لنتيجة واحدة
9. [NumeralSystem.md](NumeralSystem.md) - Enum يحدد أنظمة العد الـ 6 المدعومة
10. [NumberConverter.md](NumberConverter.md) - محرك التحويل المركزي (نمط IR)
11. [RomanConverter.md](RomanConverter.md) - محول ومحلل الأرقام الرومانية (1–3999)
12. [GematriaConverter.md](GematriaConverter.md) - محول ومحلل حساب الجمل العبري (1–3999)
13. [ExpressionEvaluator.md](ExpressionEvaluator.md) - محرك حساب التعابير الرياضية
14. [ConversionResult.md](ConversionResult.md) - نموذج تخزين نتائج التحويل
15. [CalculatorResult.md](CalculatorResult.md) - نموذج تخزين نتائج الحسابات

# Подробное описание класса: NumberConverter

#### 1. Общая информация
- **Имя класса:** `NumberConverter`
- **Тип:** Служебный класс (Центральный движок конвертации)
- **Роль в приложении:** Преобразует входную строку из любой системы счисления в десятеричное число `long`, проверяет диапазон [1..3999] и форматирует число во все 6 систем счисления.
- **Аналогия из жизни:** Переводчик в ООН, который сначала переводит речи всех участников на универсальный язык (десятеричную систему), а с него — на все остальные языки.

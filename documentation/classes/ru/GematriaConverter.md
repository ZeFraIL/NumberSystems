# Подробное описание класса: GematriaConverter

#### 1. Общая информация
- **Имя класса:** `GematriaConverter`
- **Тип:** Служебный класс (Конвертер еврейской гематрии)
- **Роль в приложении:** Парсит и форматирует буквенную гематрию (1–3999), включая тысячи (א', ב', ג'), особые случаи (15=טו, 16=טז) и пунктуацию (', ").

# Подробное описание класса: ConverterFragment

#### 1. Общая информация
- **Имя класса:** `ConverterFragment`
- **Тип:** Fragment (Контроллер UI)
- **Роль в приложении:** Управляет интерфейсом конвертера чисел ("All Types"). Считывает ввод, проверяет корректность, вызывает `NumberConverter.convertAll()` и открывает `CustomResultsDialog`.

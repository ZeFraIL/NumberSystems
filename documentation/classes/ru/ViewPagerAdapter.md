# Подробное описание класса: ViewPagerAdapter

#### 1. Общая информация
- **Имя класса:** `ViewPagerAdapter`
- **Тип:** FragmentStateAdapter
- **Роль в приложении:** Адаптер фрагментов для `ViewPager2` в `MainActivity`, обслуживающий `ConverterFragment` (вкладка 0) и `CalculatorFragment` (вкладка 1).

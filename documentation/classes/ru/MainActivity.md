# Подробное описание класса: MainActivity

#### 1. Общая информация
- **Имя класса:** `MainActivity`
- **Тип:** Activity (Главный экран-контейнер)
- **Роль в приложении:** Главный контейнер для двух вкладок: "Converter" и "Calculator".
- **Взаимодействие:** Запускается из `SplashActivity`, управляет `ViewPager2` и `TabLayout`.

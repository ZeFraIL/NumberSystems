# Подробное описание класса: CalculatorFragment

#### 1. Общая информация
- **Имя класса:** `CalculatorFragment`
- **Тип:** Fragment (Контроллер UI)
- **Роль в приложении:** Управляет интерфейсом калькулятора выражений. Считывает выражение, обрабатывает кнопки операторов (`+`, `-`, `*`), вызывает `ExpressionEvaluator.evaluate()` и открывает `CustomResultsDialog`.
